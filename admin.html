Banner Entre as Grades de Produtos

Banners de Categoria (3 blocos)

Os 3 blocos da home + banner interno (1440×250) exibido no topo de cada página de categoria. O rótulo pode ser editado no cabeçalho de cada bloco.

Banners Internos de Categoria

Banner (1440×250) exibido no topo da página de qualquer categoria — Brasileirão, La Liga, Palmeiras, Retro Palmeiras, etc. A Chave deve corresponder ao parâmetro v= da URL da categoria.

Menu de Categorias e Ligas

Ative/desative cada categoria no menu de navegação. Edite os times que aparecem em cada subcategoria.

Publicar Alterações no Site

Após salvar banners e menu acima, clique para baixar o arquivo de configuração. Substitua o site-config.json na pasta do projeto e faça git commit + push.
